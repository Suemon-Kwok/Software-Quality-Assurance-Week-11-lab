Defect ID: D-001
Title: Discount calculation subtracts discount value instead of percentage
Description: The ApplyDiscount method subtracts discountPercent directly from the price (price - discountPercent) instead of calculating the percentage discount (price - price * discountPercent / 100). A 20% discount on a $200 order therefore removes $20 instead of $40.
Steps to Reproduce:
1. Create an OrderService object.
2. Call ApplyDiscount(200, 20).
Expected Result: 160
Actual Result: 180
Severity: High
Priority: High
Status: Closed
Owner: Developer
Evidence: MSTest failed in Test Explorer. Expected result did not match actual result. (Failing test: D001_ApplyDiscount_WhenPriceIs200AndDiscountIs20_Returns160 - Expected: 160, Actual: 180.)
Resolution Notes: Production code updated. Discount percentage formula and free shipping boundary condition corrected. ApplyDiscount now returns price - (price * discountPercent / 100) and rejects invalid inputs (negative price, discount < 0 or > 100) with ArgumentException.
Retest Result: Passed. Original defect is no longer reproducible. (Retest method: D001_ApplyDiscount_WhenPriceIs200AndDiscountIs20_Returns160 - PASSED)
Final Status: Closed

Status history (life cycle):
  New -> Assigned -> Open / In Progress -> Fixed -> Pending Retest -> Verified -> Closed

Retest Result: Passed after fix was restored. (Retest method: D002_IsEligibleForFreeShipping_WhenOrderTotalIs100_ReturnsTrue - PASSED)
